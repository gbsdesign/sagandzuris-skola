# დავალების შაბლონი

Claude-ს დავალება ასე დაწერეთ — რაც უფრო ნათელია, მით ნაკლებს ეძებს და ნაკლებ ტოკენს (ფულს) ხარჯავს.

```
რა: (რა უნდა გაკეთდეს ან შეიცვალოს)
სად: (რომელ გვერდზე / რომელ ღილაკზე / რომელ გალობაზე)
როგორ უნდა იყოს: (რა შედეგი გინდათ)
რა არ შეეხოს: (რა დარჩეს როგორც არის)
მაგალითი: (სურათი, ბმული ან მსგავსი რამ, თუ გაქვთ)
```

## მაგალითები

**კარგი:**
```
რა: ღილაკი „შემდეგი“ უფრო დიდი გახდეს
სად: ნოტების გვერდი, ეკლესიის რეჟიმში, ზემოთ
როგორ უნდა იყოს: ტელეფონზე თითით ადვილად დასაჭერი
რა არ შეეხოს: დანარჩენი ღილაკები და ფერები
```

**ცუდი:** „ნოტების გვერდი გააუმჯობესე“ — Claude-ს მთელი გვერდის შესწავლა მოუწევს და შეიძლება ის შეცვალოს, რაც არ გინდოდათ.

## მზა ბრძანებები (სკილები)

| დაწერეთ | რას აკეთებს |
|---|---|
| `/add-recording` | Drive-ის საქაღალდიდან ჩანაწერს მიაბამს გალობაზე. მიაწოდეთ საქაღალდის ბმული და რომელ გალობას / ვერსიას ეკუთვნის |
| `/publish` | შეამოწმებს, რომ ყველაფერი მუშაობს, და საიტზე გამოაქვეყნებს |
| `/phone-check` | გვერდს ტელეფონის ზომაზე შეამოწმებს. დაწერეთ, რომელი გვერდი |
| `/update-calendar` | ახალი წლის საეკლესიო კალენდარს ჩამოტვირთავს (2027 — როცა orthodoxy.ge გამოაქვეყნებს) |

| რა გააკეთოთ | რატომ |

| **ახალი საქმე → ახალი საუბარი.** VS Code-ში `/clear` ან ახალი ჩატი; ღრუბელში ახალი სესია | Claude ყოველ პასუხზე მთელ წინა საუბარს ხელახლა კითხულობს — გრძელი ჩატი ყოველ ნაბიჯზე ძვირდება |
| **გრძელ საუბარში `/compact`** | საუბარს მოკლე შეჯამებად აქცევს და აგრძელებს |
| **მარტივ საქმეზე `/model` → Sonnet** (ტექსტი, ფერი, ერთი ღილაკი, ჩანაწერის მიბმა) | 2-ჯერ იაფია; რთულ საქმეზე (ახალი გვერდი, შეცდომის ძებნა) დაბრუნდით Opus-ზე |
| **დიდ საქმეზე ჯერ გეგმა:** „ჯერ გეგმა მომწერე, კოდს ნუ შეცვლი“ | არასწორი მიმართულებით გაკეთებული და გადაკეთებული სამუშაო ყველაზე ძვირია |
| **როცა ახსნა არ გჭირდებათ, დაწერეთ „მოკლედ“** | Claude-ის დაწერილი ტექსტი 5-ჯერ ძვირია წაკითხულზე |
| **ღრუბლის pull request-ი GitHub-ზე ნახეთ** და Claude-ს არ სთხოვოთ ახსნა | ნახვა უფასოა |

- **ერთ სესიაში — ერთი საქმე.** გრძელი საუბარი ყოველ ნაბიჯზე ძვირდება.
- **სურათი ჯობს ახსნას.** ეკრანის სურათი პირდაპირ აჩვენებს, რაზე ლაპარაკობთ.
- **თუ ფაილებს ეხება**, ზუსტად თქვით რომელს — მაგ. „ჰიმნო 1.pdf“ და არა „ეს ტომები“.
