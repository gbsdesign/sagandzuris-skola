# უსაფრთხოების შემოწმება

ხუთი რამ Firebase-ის კონსოლში (https://console.firebase.google.com/project/psalms-reading-group-ge-dev), ერთხელ:

1. **Project settings → Users and permissions** — მფლობელი (Owner) თქვენ ხართ.
2. **Firestore → Rules** — ჩასვით პროექტის ფაილი `firestore.rules` და დააჭირეთ Publish.
3. **Usage and billing → Budget alert** — შეტყობინება, თუ ხარჯი გაჩნდება.
4. **Google Cloud → APIs → Credentials** (https://console.cloud.google.com/apis/credentials) — API გასაღები შეზღუდეთ საიტის მისამართებზე.
5. **Authentication → Settings → Authorized domains** — მხოლოდ საიტის მისამართები.

ადრე ეს სია ადმინის პანელში, „სკოლის“ ჩანართში იდო (მხოლოდ მფლობელისთვის).
