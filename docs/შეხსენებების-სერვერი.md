# შეხსენებების სერვერის განახლება (ერთხელ გასაკეთებელი)

ფსალმუნთა ჯგუფის და დავალებების შეხსენებებს Cloudflare-ის Worker `sagandzuri-reminders` აგზავნის.
კოდი მზადაა (`worker/reminders/`). Worker-ის გამოქვეყნება ღრუბლიდან შეუძლებელია, ამიტომ შენს
კომპიუტერზე ერთხელ უნდა გაუშვა ქვემოთ მოცემული ბრძანებები. ეს დაახლოებით 10 წუთს წაიღებს.

ბრძანებები PowerShell-ში გაუშვი, პროექტის საქაღალდიდან.

## 1. ბაზა გამოწერებისთვის (D1)

```powershell
cd worker/reminders
npx wrangler d1 create sagandzuri-reminders
```

ეკრანზე გამოჩნდება `database_id = "…"`. დააკოპირე ეს id და ჩასვი ფაილში `worker/reminders/wrangler.toml`,
`PASTE-THE-ID-FROM-wrangler-d1-create`-ის ადგილას.

მერე შექმენი ცხრილები:

```powershell
npx wrangler d1 execute sagandzuri-reminders --remote --file=schema.sql
```

## 2. Firestore-ის წაკითხვის გასაღები

Worker-მა უნდა ნახოს, ვის აქვს კანონი წაუკითხავი. ამისთვის მას საიდუმლო გასაღები სჭირდება.

1. გახსენი https://console.firebase.google.com → პროექტი **psalms-reading-group-ge-dev** → ⚙️
   **Project settings** → **Service accounts**.
2. დააჭირე **Generate new private key** → **Generate key**. ჩამოიტვირთება JSON ფაილი.
   ეს ფაილი არავის გაუზიარო და GitHub-ზე არ ატვირთო.
3. PowerShell-ში (ისევ `worker/reminders` საქაღალდეში):

```powershell
Get-Content "C:\Users\<შენი სახელი>\Downloads\<ფაილის სახელი>.json" -Raw | npx wrangler secret put FIREBASE_SA
```

4. Worker-მა ფაილი ჩაიწერა, ამიტომ ჩამოტვირთული JSON ახლა შეგიძლია წაშალო.

## 3. გამოქვეყნება

```powershell
npx wrangler deploy
```

პირველ გაშვებაზე ძველი შეხსენებები (შვიდგზის ლოცვა) თავისით გადავა ახალ ბაზაში.

## 4. აუდიო-სერვერი (სატესტო მისამართებისთვის)

ჩანაწერები სატესტო მისამართებზეც (`<შტო>.sagandzuris-skola.pages.dev`) რომ ჟღერდეს:

```powershell
cd ..
npx wrangler deploy
```
